🐛 Problem Identified

The Next.js build was failing with a TypeError in the query suggestor agent:

lib/agents/query-suggestor.tsx:22:12

Type error: Cannot find name 'openai'. Did you mean 'open'?

The code was attempting to use openai.chat() but the openai variable was not defined in scope.

🔨 Solution Applied

Fixed the incorrect variable reference by using the properly imported LLM instance:

Before (line 22): 
model: openai.chat(process.env.OPENAI_API_MODEL || 'gpt-4-turbo'),
After (line 22): 
model: llm.chat(process.env.OPENAI_API_MODEL || 'gpt-4-turbo'),

Note: The llm variable is correctly imported from '@/lib/llm' and initialized as const llm = createLLM() on line 12.
