Fix #2: NVIDIA NIM Configuration Fix

Fixed

Problem: LLM wrapper incorrectly handling NVIDIA NIM model names

Location: lib/llm.ts

❌ Before

// No prefix handling - caused 500 errors from NVIDIA NIM
model = process.env.NVIDIA_NIM_MODEL || modelOverride || 'nvidia_nim/nvidia/nemotron-3-super-120b-a12b';

✅ After

// Proper prefix handling for NVIDIA NIM endpoint compatibility
model = process.env.NVIDIA_NIM_MODEL || modelOverride || 'nvidia_nim/nvidia/nemotron-3-super-120b-a12b';
// Remove nvidia_nim/ prefix if present, as NVIDIA NIM endpoint expects just the model path
if (model.startsWith('nvidia_nim/')) {
  model = model.substring(11); // Remove 'nvidia_nim/' prefix
}

Impact: Resolved Internal Server Errors (500) from NVIDIA NIM API
